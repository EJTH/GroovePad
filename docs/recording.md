# Session recording

Session recording captures GroovePad's audio output while you perform. It is separate from project saving: a project contains the editable banks and settings, while a session recording is a finished audio file.

## Record a performance

1. Open project settings by clicking the BPM display.
2. Choose a supported recording format.
3. Press the record button in the transport.
4. Perform or start playback.
5. Press record again to stop.

The browser downloads `groovepad-session.<format>` when recording finishes. Recording errors appear in a dismissible alert.

## Project versus session

- Use **Save project** when you want to continue editing the arrangement.
- Use **Record session** when you want to export what is heard during a performance.
