# Sample assets

GroovePad keeps imported sample data with the project so sample-based instruments can continue to use it after the project is reopened.

## Asset management

Open **Menu → Manage assets** to review the samples stored in the current project. From there you can remove an asset or replace it. Replacing an asset updates every bank that references the original sample source.

Assets are also included when you save a project archive. When importing a project or bank, GroovePad validates embedded sample data before adding it to the workspace.

## When to manage assets

- Remove unused samples to keep project archives smaller.
- Replace a sample without editing every Sample Hit or Sample Loop control.
- Keep related samples together in the same project.
