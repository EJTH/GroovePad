# GroovePad.js

A mobile-first groovebox built with Vue 3, TypeScript, and Vite.

## Development

Run `npm run dev` to start the development server. Run `npm run build` to type-check and create a production build.

## GitHub Pages

Set the repository's **Settings > Pages > Build and deployment > Source** to **GitHub Actions**. The build workflow tests and builds the site on every push and pull request, and deploys `dist` to Pages after successful pushes to `main`. It can also be run manually on `main`. The Pages build uses relative asset paths so it works under a repository subpath.

## Current functionality

The header contains the transport controls, tempo and current bank display, and beat indicator. Below it are the bank selector and editable grid. Each bank has its own layout, initially 4 by 4, with up to 8 columns and 10 rows. Enable edit mode with the header button, then tap a **+** cell, choose a control from the icon grid, and save its settings. Expand the name and size summary in control settings to edit its type, name, color and layout. Instrument pads have a separate icon grid for choosing their instrument type. Tap an existing control to edit or remove it. Drag a control to an empty cell to move or copy it, or onto another control to swap them when both fit. Copies do not include wires. Drag a corner to resize. Turn off edit mode to play. **Grid settings** changes the number of columns and rows; controls cannot overlap or extend outside the grid.

Tapping a resize corner without dragging also opens the control's settings, including on small grid cells.

Numeric settings offer both a knob and an input for precise entry. Knobs for unbounded values adjust over an adaptive range; enter a larger or smaller value to change that range.

Drag knobs right or up to increase their value, and left or down to decrease it. These directions rotate with the control. Mouse wheels and horizontal trackpad scrolling also adjust them.

Every grid control has a **Control orientation** setting under Layout. Vertical rotates the entire control clockwise, including its label; horizontal leaves it upright. The piano roll's separate keyboard layout setting determines how its keys are arranged before rotation.

Use the edit button in the header to add controls, then the wire button to its left to drag from a source to a destination and select their compatible parameters. Knobs can be wired to LFO rate, waveform, depth or offset. Selectable settings divide the 0–127 input range evenly among their options, in menu order. LFO offset shifts the waveform, with output limited to -1 through 1. Banks, controls, and wires are saved in browser storage.

LFO settings include an animated preview using the draft settings and project tempo. Tap the preview to hold or resume it without affecting the grid. LFOs, arpeggiators and sequenced loops have configurable colors in their control settings.

LFOs, knobs and mod wheels can also control the numeric and selectable sound settings of Sample Hit, Sample Loop, 303 and 808 instrument pads. Sample playback mode, loop mode and reverse, and 808 drum type are selectable destinations. Sample pitch, volume and envelope settings update active voices; playback mode, direction and drum settings take effect on the next trigger. Sample files, waveform markers and instrument type are not modulation destinations.

Wired knobs add their current value to the destination's configured value; their minimum can be negative. An auto-centering mod wheel adds or subtracts up to its depth as a fraction of the destination range, returning to zero adjustment at the center. Adjustments are clamped to the destination range and do not overwrite its saved base value.

In the connect dialog or either control's settings, use **MOD** or **ABS** on a numeric connection and set its minimum and maximum endpoints. MOD adds offsets from -100% to 100% of the destination's range to its configured value. ABS sets actual destination values; for selectable settings, choose the endpoint options instead. The source's minimum and maximum map to the endpoints, with linear interpolation between them; reversed and equal endpoints are supported. Switching from MOD to ABS clamps negative percentages to zero before converting them to destination values. Blank ABS endpoints use the destination's minimum and maximum; blank MOD endpoints default to -100% for the minimum of a bipolar source or 0% otherwise, and 100% for the maximum. Older percentage-based ABS and single-amount mappings retain their behavior. For an Output Selector, MOD offsets the incoming numeric signal or the user-selected output, respectively; ABS sets the signal or output selection. Note connections do not have numeric mappings.

An Output Selector accepts one number or note input and routes it to one connected destination at a time. Connect destinations of the same signal type; tap the selector to cycle through them in wire creation order. Its separate Output selection input scales the source's output range to 0–127, then maps it evenly across those destinations. It displays the selected control and input name and the latest incoming signal value, and briefly highlights the newly selected destination when tapped. Held notes move to the newly selected destination.

Piano rolls have a configurable color and show note names. The arpeggiator runs while it receives held notes, for example from a wired piano roll, and displays the current note name. Tap it to toggle between arpeggiation and passing notes through unchanged. Its **On/off** input can also be wired to a numeric output: values 0–63 select off and 64–127 select on after mapping. A wire changes the effective state without overwriting the saved toggle; an active ABS wire takes precedence over taps. Its rate uses note divisions at the displayed tempo. Steps sets the number of transposed distance levels beyond the original notes; each level contains all held notes. Distance transposes successive levels in semitones. Every style starts at the untransposed level; Down plays the notes in descending order within each level. Non-chromatic scales quantize transposed notes upward relative to each held note.

New arpeggiators default to distance 12 and steps 0; existing saved settings are unchanged.

A **Sequenced Loop** records notes played on instrument pads while the transport is playing and **Armed for record** is checked. **Record from** selects the loop's own bank (default) or all banks; this setting applies to all its clips. Recording overdubs the selected **Clip index** (0–15); choosing an unused index creates an empty clip. The clip index can also be wired to a numeric control; the wire selects the effective clip without overwriting the saved index. Each note retains its bank, instrument, pitch, velocity, initial bend and duration. Loop playback is not recorded again. Notes whose original instrument or bank has been removed are skipped.

While the transport is stopped, tap a loop to arm or disarm recording. While it is playing, tap an unarmed loop to enable or disable playback; the red record icon shows when it is armed. An armed loop automatically starts and stays enabled while the transport is running; disarm it in settings or when the transport is stopped. **Bar length** is 1–64 bars of four beats; all clips in that loop share the length. **Immediate** starts at once, while **Sync to clip length** starts at the next matching transport boundary. All banks remain live when not displayed; switching banks does not stop their loops or instruments. Editing a bank suspends its loops until edit mode is exited or another bank is selected, then restarts them according to their sync modes. Stopping the transport stops loop playback. Recordings and clip settings are saved with the project.

The loop settings show a tracker for the chosen clip. Add an instrument/note row, then tap a 1/16 step to add a note. Tap an event to edit its instrument, pitch, velocity, position or duration; tap a single event again or use Delete to remove it. When a step contains multiple events, choose one from the event list. Recorded timings remain unchanged until edited. Zoom with the timeline buttons and scroll horizontally to pan. Instrument rows use their pad colors; recorded control automation appears in separate rows whose events can also be edited or deleted. Changing the clip index opens that clip, creating it if needed.

**Record quantize** snaps newly recorded note starts to the nearest 1/4, 1/8, 1/16 or 1/32 note; Off preserves their timing. Notes rounded to the loop end wrap to its start. Existing notes, note durations, editor placement and automation timing are not changed.

Armed loops also record user-generated knob and mod-wheel movements and pad/piano velocity, pressure and gate outputs while the transport runs. Knob and mod-wheel settings include **Record automation for this control**, enabled by default; disabling it stops new automation from that control being recorded without affecting existing playback. On playback these changes drive the original controls' existing wires; moving a control yourself takes priority while it is being used. If multiple loops automate the same output, the most recently played event takes precedence. Automation is not generated from LFOs or sequencer playback and does not replace saved base settings.

Use the menu to add a bank, edit its title, icon, color and grid dimensions, or remove it after confirmation. A long press on a bank also opens its settings. **Add bank from file** accepts a project ZIP and lets you choose a bank, or accepts an individual bank JSON file. Project settings changes the tempo. The browser automatically saves the current project locally.

Sample Hit and Sample Loop pads accept local audio files up to 2 MB, or record from a microphone with **Record** and **Stop**. Recording requires microphone permission and a secure browser context (HTTPS or localhost). Recordings are numbered mono 16-bit WAV files and have no fixed time limit, but large recordings may exceed browser storage or the project export limit. **Reset** removes the sample and its markers.

Samples imported or recorded are kept in the project asset library, even after resetting or removing a pad. In Sample Hit settings, use the archive button to load a project sample. The menu's **Manage assets** opens the same library without selection and lets you swap a sample for a local audio file in every pad using it. Deleting a sample requires pressing Delete twice and unsets it from all pads using it; swapping or deleting resets their waveform markers. Existing projects' embedded pad samples are added to the library when loaded.

The waveform editor lets you drag to pan, scroll or pinch to zoom, and drag the start, end and cut markers. Choose **Add cut** and tap the waveform to split the selected region; remove cuts with the corresponding buttons. With cuts present, choose random, sequential or a specific cut for each trigger. For Sample Hit, choose **Loop mode** under Playback to select Loop or Back and forth; reverse playback is also available. When looping, it plays the lead-in and repeats between the first and last cuts; one cut loops from start to that cut, and no cuts loop the whole region. Sample Loop repeats the selected cut. On release, looping continues as the envelope fades, then exits at a loop boundary to play the tail toward the region's end (or start when moving backward). If the tail cannot fit, it begins immediately and fades out at the end of release. Raise envelope sustain above zero to hear held loops; release can be set up to 10 seconds. Samples are embedded in the project; browser storage is limited and reports an error if its quota is exceeded.

Sample Hit's **Polyphony** sets the maximum number of sounding voices from 1 to 16 (default 1). Higher values let wired piano rolls play chords, including through note-routing controls; each pitch has its own release and glide bend. When the limit is reached, the oldest sounding voice is stopped. Multiple sources holding the same pitch share a held note until all release it. Other instruments remain monophonic.

Hold **Play** in an instrument's settings header to preview the current settings, and release it as you would a pad.

New instruments default to 100% sustain and a 0.5-second release, including the 303 filter envelope. Existing saved settings are unchanged.

Use **Save project** to download a ZIP and **Load project** to choose one. Loading validates the complete project before replacing the current one. The version 1 archive contains `manifest.json`, one JSON configuration per bank under `banks/`, audio files under `samples/`, and an empty `loop_midi/` directory. Sample names are made unique in the archive when necessary. Older projects with embedded samples remain supported. The project limit is 20 MB uncompressed. Archives containing separate MIDI files are not supported. Legacy sample URLs are cleared when loading; choose a local file instead. A bank whose loops target other banks must be loaded as part of its complete project, rather than imported alone.

Pads and piano rolls expose velocity (0–127, set at note-on) and pressure (0–127, updated while held) as wireable outputs. Both support the same mapping modes as other numeric sources. Pressure-sensing pointers use pressure; other pointers use position from top to bottom, or left to right on a vertical piano roll. Keyboard presses use 100. The piano roll outputs the average pressure of all held contacts, rounded to the nearest integer. Once all contacts are released, pressure stops driving connected controls. Arpeggiators expose the velocity of each outgoing note, including in bypass mode. The header's separate recording button is not implemented yet.

The piano roll's **Pressure mode** can instead force position on the key, even when a device reports pressure. This also sets the note-on velocity. Pressure sensing mode retains the position fallback for pointers that do not report usable pressure.
